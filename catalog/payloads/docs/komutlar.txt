VACİB QEYD Bu sənəd Nibras Terminal layihəsinin ilkin qurulması, Android
build, Git, test və Linux mühiti prototipi üçün komutları bir yerə
toplayır. Bu, hələ mövcud olmayan tətbiqin bütün funksiyalarını hazır
edən sehrli komut siyahısı deyil. Komutlar müvafiq kod modulları
yaradıldıqdan sonra işləyəcək. Layihənin real qovluq adları və Gradle
modul adları yaradılan Android layihəsinə uyğunlaşdırılmalıdır.

TƏHLÜKƏSİZLİK - Naməlum mənbədən rootfs və executable fayl yükləməyin. -
Rootfs arxivinin SHA-256 dəyərini rəsmi mənbə ilə yoxlayın. - sudo, su
və root tələb edən komutları bu layihənin normal iş axınına daxil
etməyin. - İstifadəçinin fayllarını silən komutları təsdiqsiz icra
etməyin. - GitHub tokenini kodun içinə yazmayın. - Aşağıdakı
nümunələrdəki URL, paket və versiyaları real buraxılışdan əvvəl
yoxlayın.

============================================================ 3. ANDROID
LAYİHƏSİNİN YARADILMASI
============================================================

TÖVSİYƏ: Android Studio-da yeni layihə yaradın: - Template: Empty
Activity - Language: Kotlin - UI: Jetpack Compose - Minimum SDK:
layihənin test hədəfinə uyğun seçin - Package: com.nibras.terminal

Layihə yaradıldıqdan sonra terminalda: ./gradlew –version ./gradlew
tasks ./gradlew assembleDebug ./gradlew test ./gradlew lint

Debug APK: app/build/outputs/apk/debug/app-debug.apk

Telefona quraşdırmaq: adb install -r
app/build/outputs/apk/debug/app-debug.apk

Tətbiqi açmaq üçün (package adı uyğunlaşdırılmalıdır): adb shell monkey
-p com.nibras.terminal 1

Logları izləmək: adb logcat adb logcat | grep -i nibras

Təmiz build: ./gradlew clean ./gradlew assembleDebug

Release build (signing konfiqurasiyası tələb edir): ./gradlew
assembleRelease

AAB: ./gradlew bundleRelease

QEYD: Release signing məlumatlarını Git-ə göndərməyin. Keystore və
parolları təhlükəsiz yerdə saxlayın.

============================================================ 5. ROOTFS
YÜKLƏMƏ VƏ YOXLAMA ŞABLONU
============================================================

XƏBƏRDARLIQ: Debian və Ubuntu rootfs arxivlərinin konkret URL-ləri,
arxiv formatları və SHA-256 dəyərləri rəsmi buraxılışa görə dəyişir.
Burada uydurma URL və checksum verilmir. Yalnız rəsmi, yoxlanıla bilən
mənbədən götürülmüş dəyərlərdən istifadə edin.

Rootfs qovluğu: mkdir -p downloads mkdir -p rootfs/debian mkdir -p
rootfs/ubuntu

Yüklənmiş arxivin checksum yoxlaması: sha256sum
downloads/ROOTFS_ARCHIVE.tar.* # Nəticəni rəsmi mənbədə göstərilən
SHA-256 ilə müqayisə edin.

Arxivin məzmununa baxmaq: tar -tf downloads/ROOTFS_ARCHIVE.tar.*

Arxivi açmaq nümunəsi: tar -xf downloads/ROOTFS_ARCHIVE.tar.* -C
rootfs/debian

QEYD: Yuxarıdakı açma komutu arxivin formatına və qovluq strukturuna
görə dəyişə bilər. Android tətbiqində rootfs quraşdırılması üçün ayrıca
təhlükəsiz installer kodu yazılmalıdır. Bu shell komutunu birbaşa
tətbiqə köçürmək kifayət deyil.

ENGINE ÜÇÜN TƏTBİQ DAXİLİ ƏMƏLİYYAT SİYAHISI

Aşağıdakılar istifadəçinin görəcəyi funksional əməliyyatlardır. Bunlar

stopProcess(processId) - listProcesses() - streamOutput(processId)

PackageManager: - searchPackages(query) - installPackage(packageName) -
removePackage(packageName) - updatePackageIndex() - upgradePackages() -
listInstalledPackages()

ProjectManager: - createProject(template, name) - importProject(uri) -
exportProject(projectId, destination) - openProject(projectId) -
deleteProject(projectId)

ServerManager: - startServer(projectId, host, port) -
stopServer(serverId) - listServers() - getServerLogs(serverId)

Bu API-lər üçün Kotlin interface-ləri, implementasiyalar, testlər və
