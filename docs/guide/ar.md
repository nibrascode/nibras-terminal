# نبراس تيرمينال — دليل الاستخدام (العربية)

[→ العودة إلى README](../../README.md) · [جميع اللغات](../../README.md#-guides-in-your-language)

## ١. ما هو نبراس تيرمينال؟

نبراس تيرمينال طرفية لينكس كاملة لهواتف أندرويد. يفتح التطبيق مباشرة على طرفية حقيقية، ويعمل فيه نظام Alpine Linux جاهزًا دون أي إعداد، ويمكنك إضافة Debian وUbuntu وArch وFedora وKali متى احتجت إليها. ويضم التطبيق محرر أكواد يدعم خوادم اللغات، ومدير ملفات، وعميل SSH، وأدوات لبناء ملفات APK وتعديلها، وأدوات للوسائط، ومجموعة كبيرة من الأوامر الخاصة بنبراس وحده. ويبقى حجم التطبيق صغيرًا لأن الأدوات الثقيلة لا تُنزَّل إلا عندما تطلبها.

## ٢. التثبيت والتشغيل الأول

1. نزّل أحدث ملف APK من صفحة المشروع على GitHub ‏(Actions ← *Android package* ← artifact) أو من الرابط الذي أرسله لك المطوّر.
2. افتح الملف واسمح بخيار «تثبيت التطبيقات غير المعروفة» عندما يطلبه أندرويد.
3. عند التشغيل الأول يعرض نبراس تيرمينال شاشة لاختيار اللغة. تظهر كل لغة باسمها الأصلي، وتكون لغة هاتفك محددة مسبقًا. وإذا لم تتوفر لغة هاتفك تُستخدم الإنجليزية.
4. تُجهَّز بيئة Alpine Linux المدمجة تلقائيًا، ثم تُفتح الطرفية.

يمكنك تغيير اللغة في أي وقت بالأمر `lang` أو من الإعدادات.

## ٣. الأساسيات

- اسحب من الحافة اليسرى للشاشة، أو اضغط `☰` في صف المفاتيح الإضافية، لفتح القائمة الجانبية التي تحتوي على الجلسات والبيئات والأدوات والإعدادات.
- اضغط مطولًا على جلسة لإعادة تسميتها أو إغلاقها. واضغط مطولًا على «جلسة جديدة» لاختيار البيئة (Alpine أو Debian أو Ubuntu أو صدفة أندرويد).
- يوفر صف المفاتيح الإضافية مفاتيح `ESC` و`TAB` و`CTRL` و`ALT` والأسهم وغيرها. ويبقى `CTRL` و`ALT` مضغوطين حتى المفتاح التالي.
- يعمل زر خفض الصوت عمل `CTRL`، ويعمل زر رفع الصوت معدِّلًا للمفاتيح الإضافية.
- اكتب `nibras` لفتح قائمة جميع أدوات نبراس، واكتب `help` لعرض قائمة مختصرة بالأوامر.

</div>

```sh
nibras
help
```

## ٤. تثبيت الأدوات بالأمر `install`

لا تُخزَّن الأدوات داخل ملف APK. اكتب `install` لعرض جميع الحزم مع وصف مختصر لكل منها، واكتب `install <الاسم>` لإضافة إحداها. أما البرامج التي ليست من حزم نبراس فتُثبَّت بالأمر `pkg install <الاسم>`.

</div>

```sh
install
install python
install video
install dev
pkg install htop
```

## ٥. بيئات لينكس (التوزيعات)

نظام Alpine Linux مدمج في التطبيق. أما التوزيعات الأخرى فتُنزَّل عند الطلب، وتعمل كل واحدة منها بيئةً مستقلة.

</div>

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## ٦. لغات البرمجة والأمر `run`

يتعرّف الأمر `run` على الملف من امتداده، ويثبّت الأداة اللازمة في المرة الأولى، ثم يشغّل الملف. وهو يعمل مع Python وJavaScript وTypeScript وJava وKotlin وC وC++‎ وGo وRust وPHP وRuby وPerl وLua وDart وR وJulia وHaskell وElixir وZig وNim وBash وPowerShell وغيرها. وعندما تعطيه مجلدًا فإنه يكتشف نوع المشروع بنفسه (Cargo، ووحدات Go، وnpm، وGradle، وCMake، وMakefile وغيرها).

</div>

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## ٧. محرر الأكواد وLSP

افتح ملفًا بالأمر `edit <الملف>` أو من مدير الملفات. يلوّن المحرر صياغة أكثر من ٢٥ لغة، ويكمل الكلمات المفتاحية والمقتطفات، وينسّق الشيفرة، ويعرض معاينة لملفات Markdown وHTML وتخطيطات أندرويد، ويشغّل الملف بالزر ▶.

للحصول على إكمال ذكي، وتسطير الأخطاء، وعرض المعلومات عند التمرير، والانتقال إلى التعريف، ثبّت خادم اللغة مرة واحدة. ويظهر الرمز 🧠 في شريط الحالة عندما يعمل الخادم.

</div>

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

<div dir="rtl">

اضغط مطولًا على كلمة في المحرر لعرض توثيقها. وتحتوي القائمة ⋯ على «المشكلات» و«معلومات عند المؤشر» و«الانتقال إلى التعريف».

## ٨. مدير الملفات

افتح مدير الملفات من القائمة الجانبية أو بالأمر `files`. يمكنك نسخ الملفات ونقلها وإعادة تسميتها وحذفها وضغطها وفك ضغطها ومشاركتها وفتحها، ويمكنك الوصول إلى ذاكرة الهاتف بعد تشغيل الأمر `nibras-setup-storage`.

</div>

```sh
files
nibras-setup-storage
```

<div dir="rtl">

## ٩. SSH

تحفظ شاشة SSH في القائمة الجانبية خوادمك ومفاتيحك وتوجيهات المنافذ وخوادم القفز. ويدعم التطبيق Mosh وTelnet وSFTP. ويمكنك أيضًا تشغيل خادم SSH على الهاتف.

</div>

```sh
ssh user@example.com
nibras-sshd
```

<div dir="rtl">

تُصدَّر الخوادم وتُستورَد في صورة ملف `ssh config`، لذا يمكنك نقلها بين الأجهزة دون حساب سحابي.

## ١٠. أدوات APK ومحرر الموارد

تبني الأداة `nibras-apk` تطبيقات أندرويد وتفككها وتعدّلها وتوقّعها على الهاتف نفسه.

</div>

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

<div dir="rtl">

يتيح لك محرر الموارد المرئي (`nibras-apk res`) تحرير النصوص لكل لغة في جدول، وتغيير الألوان، واستبدال الأيقونات والصور من المعرض، وتغيير اسم التطبيق واسم الحزمة والإصدار. ثم تعيد لمسة واحدة بناء التطبيق وتوقيعه وتثبيته. ولم تُضَف عمدًا أي ميزات تكسر فحص التراخيص أو حماية تطبيقات الآخرين.

تفهم الطرفية عبارات طبيعية بعدة لغات، ولا يهم فيها حجم الأحرف.

</div>


<div dir="rtl">

تُعرَض الشاشات العربية والفارسية والأردية من اليمين إلى اليسار. ولعرض النص العربي داخل الطرفية بحروف متصلة استخدم الأمر `rtl`، مثلًا: `cat note.txt | rtl`.

## ١٤. ميزات لا توجد إلا في نبراس

- تساعدك الأوامر `ask` و`explain` و`fix` في فهم الأوامر وحل الأخطاء.
- يحتوي `recipes` و`learn` على حلول جاهزة ودروس في لينكس.
- يحفظ `vault` الملفات الخاصة مشفّرة، ويجعل `trash` الحذف آمنًا.
- الأوامر `quran` و`hadith` و`prayer` (مع التذكيرات) مدمجة في التطبيق.
- يشغّل `llm` محادثة ذكاء اصطناعي دون اتصال على الهاتف.
- يفتح `webterm` هذه الطرفية في متصفح حاسوب عبر شبكة Wi-Fi.
- تعمل الشاشة المقسومة والنافذة العائمة وسطح مكتب لينكس (XFCE) داخل التطبيق.

## ١٥. الأذونات

لا يطلب نبراس تيرمينال إذنًا إلا عندما يحتاج إليه أمر ما. تطلب أوامر الكاميرا والميكروفون والموقع وجهات الاتصال والرسائل القصيرة الإذن عند أول استخدام. ويلزم إذن «تثبيت التطبيقات غير المعروفة» لتثبيت ملفات APK التي تبنيها. ويلزم إذن «المنبّهات والتذكيرات» لتذكيرات الصلاة. أما الوصول إلى الإشعارات، و«تعديل إعدادات النظام»، والاقتران بتصحيح الأخطاء اللاسلكي (`nibras-adb pair`) فهي اختيارية، ولا تستخدمها إلا الأوامر التي تذكرها. ودون صلاحيات الجذر (root) تستخدم مشاركة ملفات Windows المنفذ 4445 بدلًا من 445، ولا تتوفر الأدوات المعتمدة على FUSE مثل `sshfs`.

## ١٦. حل المشكلات

- إذا لم يكن الأمر موجودًا فاكتبه على أي حال، وسيقترح عليك نبراس الحزمة المناسبة.
- إذا توقف التثبيت فأعد تشغيل أمر `install` نفسه؛ إذ يُستأنف التنزيل ويُتحقَّق منه.
- يطبّق الأمر `nibras-reload-settings` التغييرات التي أجريتها على ملفات الإعدادات.
- إذا أُغلق التطبيق فجأة يُحفَظ تقرير الخطأ في الملف `crash.txt`، ويعرض عليك التطبيق في التشغيل التالي عرضه ومشاركته. يُرجى إرفاق هذا الملف عند الإبلاغ عن مشكلة على GitHub.

## ١٧. الأسئلة الشائعة

**هل نبراس تيرمينال مجاني؟** نعم، وهو مفتوح المصدر.

**هل يحتاج إلى صلاحيات الجذر؟** لا. كل شيء يعمل دون root، ولا تُقيَّد إلا بعض المهام على مستوى النظام كما ذُكر أعلاه.

**لماذا حجم التطبيق صغير جدًا؟** لا يحتوي إلا على Alpine Linux والترجمات، وكل ما عدا ذلك يُنزَّل بالأمر `install` عند الحاجة.

**هل يعمل على الهواتف ذات ٣٢ بت؟** نعم. ملف APK واحد يدعم أجهزة arm64 وarm32 معًا.
