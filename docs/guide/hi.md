# Nibras Terminal — उपयोगकर्ता गाइड (हिन्दी)

[← README पर वापस जाएँ](../../README.md) · [सभी भाषाएँ](../../README.md#-guides-in-your-language)

> फ़ोन ऐप और वेब टर्मिनल एक ही प्रोग्राम नहीं हैं। कैमरा, माइक्रोफ़ोन, SMS, संपर्क और कॉल लॉग केवल फ़ोन पर हैं, और हर बार अलग हाँ माँगते हैं। वेब उन्हें नहीं चलाता। सूची: [कमांड](../COMMANDS.md).


## 1. Nibras Terminal क्या है?

Nibras Terminal Android फ़ोन के लिए एक पूरा Linux टर्मिनल है। ऐप खुलते ही सीधे एक असली टर्मिनल दिखाता है, इसमें Alpine Linux बिना किसी सेटअप के चलता है, और ज़रूरत पड़ने पर आप कभी भी Debian, Ubuntu, Arch, Fedora और Kali जोड़ सकते हैं। इसमें लैंग्वेज सर्वर सपोर्ट वाला कोड एडिटर, फ़ाइल मैनेजर, SSH क्लाइंट, APK फ़ाइलें बनाने और बदलने के टूल, मीडिया टूल और ऐसे बहुत-से कमांड भी हैं जो सिर्फ़ Nibras में हैं। ऐप खुद छोटा रहता है, क्योंकि भारी टूल सिर्फ़ तभी डाउनलोड होते हैं जब आप उन्हें माँगते हैं।

## 2. इंस्टॉल करना और पहली बार खोलना

1. APK सीधे डाउनलोड करें: https://github.com/nibrascode/nibras-terminal/releases/latest/download/nibras-terminal.apk
कैमरा, माइक्रोफ़ोन, SMS, संपर्क और स्थान केवल वह कमांड चलाने पर माँगे जाते हैं, ऐप खुलते समय नहीं।
अपने-आप अपडेट (Obtainium): https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/nibrascode/nibras-terminal
2. फ़ाइल खोलें और जब Android पूछे, तो "अज्ञात ऐप इंस्टॉल करें" की अनुमति दें।
3. पहली बार खोलने पर Nibras Terminal भाषा चुनने की स्क्रीन दिखाता है। हर भाषा अपने ही नाम से लिखी होती है और आपके फ़ोन की भाषा पहले से चुनी होती है। अगर आपके फ़ोन की भाषा उपलब्ध नहीं है, तो अंग्रेज़ी इस्तेमाल होती है।
4. अंदर का Alpine Linux वातावरण अपने-आप तैयार हो जाता है और टर्मिनल खुल जाता है।

आप `lang` कमांड से या सेटिंग्स में जाकर कभी भी भाषा बदल सकते हैं।

## 3. बुनियादी बातें

- सेशन, वातावरण, टूल और सेटिंग्स वाला साइड मेनू खोलने के लिए स्क्रीन के बाएँ किनारे से स्वाइप करें या अतिरिक्त कुंजियों की पंक्ति में `☰` पर टैप करें।
- किसी सेशन का नाम बदलने या उसे बंद करने के लिए उसे दबाकर रखें। वातावरण (Alpine, Debian, Ubuntu या Android शेल) चुनने के लिए "नया सेशन" को दबाकर रखें।
- अतिरिक्त कुंजियों की पंक्ति में `ESC`, `TAB`, `CTRL`, `ALT`, तीर कुंजियाँ और बहुत कुछ है। `CTRL` और `ALT` अगली कुंजी तक दबी रहती हैं।
- वॉल्यूम कम करने वाला बटन `CTRL` का और वॉल्यूम बढ़ाने वाला बटन अतिरिक्त कुंजियों के मॉडिफ़ायर का काम करता है।
- सभी Nibras टूल का मेनू खोलने के लिए `nibras` लिखें, और कमांड की छोटी सूची के लिए `help` लिखें।

```sh
nibras
help
```

## 4. `install` से टूल इंस्टॉल करना

टूल APK के अंदर नहीं रखे जाते। सभी पैक को छोटे विवरण के साथ देखने के लिए `install` लिखें, और कोई पैक जोड़ने के लिए `install <नाम>` लिखें। जो प्रोग्राम Nibras पैक नहीं हैं, वे `pkg install <नाम>` से इंस्टॉल होते हैं।

```sh
install
install python
install video
install dev
pkg install htop
```

## 5. Linux वातावरण (डिस्ट्रीब्यूशन)

Alpine Linux ऐप में शामिल है। बाकी डिस्ट्रीब्यूशन माँगने पर डाउनलोड होते हैं, और हर एक अलग वातावरण के रूप में चलता है।

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## 6. प्रोग्रामिंग भाषाएँ और `run`

`run` कमांड फ़ाइल को उसके एक्सटेंशन से पहचानता है, पहली बार ज़रूरी टूल खुद इंस्टॉल करता है और फिर फ़ाइल चलाता है। यह Python, JavaScript, TypeScript, Java, Kotlin, C, C++, Go, Rust, PHP, Ruby, Perl, Lua, Dart, R, Julia, Haskell, Elixir, Zig, Nim, Bash, PowerShell और कई अन्य भाषाओं के साथ काम करता है। अगर आप इसे कोई फ़ोल्डर दें, तो यह प्रोजेक्ट का प्रकार (Cargo, Go मॉड्यूल, npm, Gradle, CMake, Makefile आदि) खुद पहचान लेता है।

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## 7. कोड एडिटर और LSP

किसी फ़ाइल को `edit <फ़ाइल>` से या फ़ाइल मैनेजर से खोलें। एडिटर 25 से ज़्यादा भाषाओं के सिंटैक्स को रंगीन करता है, कीवर्ड और स्निपेट पूरे करता है, कोड को फ़ॉर्मैट करता है, Markdown, HTML और Android लेआउट का प्रीव्यू दिखाता है और ▶ बटन से फ़ाइल चलाता है।

स्मार्ट कम्प्लीशन, गलतियों के नीचे रेखा, होवर जानकारी और परिभाषा पर जाने के लिए एक बार लैंग्वेज सर्वर इंस्टॉल करें। सर्वर चलने पर स्टेटस बार में 🧠 दिखता है।

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

किसी शब्द का दस्तावेज़ देखने के लिए एडिटर में उसे दबाकर रखें। ⋯ मेनू में "समस्याएँ", "कर्सर पर जानकारी" और "परिभाषा पर जाएँ" विकल्प हैं।

## 8. फ़ाइल मैनेजर

फ़ाइल मैनेजर को साइड मेनू से या `files` कमांड से खोलें। आप फ़ाइलें कॉपी, मूव, नाम बदल, डिलीट, कंप्रेस, एक्सट्रैक्ट, शेयर और खोल सकते हैं, और `nibras-setup-storage` चलाने के बाद फ़ोन की स्टोरेज तक भी पहुँच सकते हैं।

```sh
files
nibras-setup-storage
```

## 9. SSH

साइड मेनू की SSH स्क्रीन आपके होस्ट, कुंजियाँ, पोर्ट फ़ॉरवर्ड और जंप होस्ट सहेजती है। Mosh, Telnet और SFTP समर्थित हैं। आप फ़ोन पर SSH सर्वर भी चला सकते हैं।

```sh
ssh user@example.com
nibras-sshd
```

होस्ट एक `ssh config` फ़ाइल के रूप में एक्सपोर्ट और इंपोर्ट होते हैं, इसलिए आप उन्हें बिना क्लाउड खाते के एक डिवाइस से दूसरे डिवाइस पर ले जा सकते हैं।

## 10. APK टूल और रिसोर्स एडिटर

`nibras-apk` फ़ोन पर ही Android ऐप बनाता है, खोलता है, संपादित करता है और साइन करता है।

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

विज़ुअल रिसोर्स एडिटर (`nibras-apk res`) से आप हर भाषा के टेक्स्ट एक तालिका में संपादित कर सकते हैं, रंग बदल सकते हैं, गैलरी से आइकन और चित्र बदल सकते हैं, और ऐप का नाम, पैकेज नाम और वर्ज़न बदल सकते हैं। फिर एक टैप से ऐप दोबारा बनता है, साइन होता है और इंस्टॉल हो जाता है। दूसरों के ऐप की लाइसेंस जाँच या सुरक्षा तोड़ने वाली सुविधाएँ जानबूझकर शामिल नहीं की गई हैं।

## 11. वीडियो, ऑडियो, डाउनलोड और दस्तावेज़

```sh
video merge a.mp4 b.mp4
video cut in.mp4 00:01:00 00:02:30
video compress in.mp4
audio convert in.wav out.mp3
image resize photo.jpg 50%
pdf merge a.pdf b.pdf
download https://example.com/video
media
```

`download` किसी लिंक से वीडियो, संगीत और फ़ाइलें सहेजता है। कृपया सिर्फ़ वही सामग्री डाउनलोड करें जिसे सहेजने का आपको अधिकार है। `media` कमांड इन्हीं कामों के लिए एक विज़ुअल स्क्रीन खोलता है।

## 13. भाषा कमांड


## 14. सुविधाएँ जो सिर्फ़ Nibras में हैं

- `ask`, `explain` और `fix` कमांड और गलतियों में आपकी मदद करते हैं।
- `recipes` और `learn` में तैयार समाधान और Linux के पाठ हैं।
- `vault` निजी फ़ाइलों को एन्क्रिप्ट करके रखता है, और `trash` डिलीट करने को सुरक्षित बनाता है।
- `quran`, `hadith` और `prayer` (रिमाइंडर के साथ) ऐप में शामिल हैं।
- `llm` फ़ोन पर ऑफ़लाइन AI चैट चलाता है।
- `webterm` इस टर्मिनल को Wi-Fi के ज़रिए कंप्यूटर के ब्राउज़र में खोलता है।
- स्प्लिट स्क्रीन, फ़्लोटिंग विंडो और Linux डेस्कटॉप (XFCE) ऐप के अंदर काम करते हैं।
- `scripts` स्क्रिप्ट स्टोर खोलता है, जहाँ आप तैयार स्क्रिप्ट देख, पढ़, इंस्टॉल और चला सकते हैं।
- `remote` इस टर्मिनल को उसी Wi-Fi पर मौजूद कंप्यूटर के ब्राउज़र में खोलता है। एक बार काम करने वाला लिंक QR कोड के रूप में भी दिखाया जाता है।
- `backup drive` आपके होस्ट और सेटिंग्स को आपके अपने पासफ़्रेज़ से एन्क्रिप्ट करके Google Drive या किसी भी फ़ोल्डर में सहेजता है। `restore drive` उन्हें वापस लाता है।
- `learn` इंटरैक्टिव पाठ शुरू करता है: आप असली कमांड लिखते हैं और उनकी जाँच अपने आप होती है।
- होम-स्क्रीन विजेट आपकी पसंदीदा कमांड एक टैप में चलाते हैं और सर्वर की स्थिति तथा नमाज़ के समय दिखाते हैं।

## 15. अनुमतियाँ

Nibras Terminal कोई अनुमति सिर्फ़ तभी माँगता है जब किसी कमांड को उसकी ज़रूरत हो। कैमरा, माइक्रोफ़ोन, लोकेशन, संपर्क और SMS कमांड पहली बार इस्तेमाल करने पर अनुमति माँगते हैं। आपकी बनाई हुई APK फ़ाइलें इंस्टॉल करने के लिए "अज्ञात ऐप इंस्टॉल करें" ज़रूरी है। नमाज़ के रिमाइंडर के लिए "अलार्म और रिमाइंडर" ज़रूरी है। सूचना ऐक्सेस, "सिस्टम सेटिंग्स बदलें" और वायरलेस डीबगिंग पेयरिंग (`nibras-adb pair`) वैकल्पिक हैं और सिर्फ़ वही कमांड इनका इस्तेमाल करते हैं जो इनका ज़िक्र करते हैं। रूट के बिना Windows फ़ाइल शेयरिंग 445 की जगह पोर्ट 4445 इस्तेमाल करती है, और `sshfs` जैसे FUSE पर आधारित टूल उपलब्ध नहीं होते।

## 16. समस्या निवारण

- अगर कोई कमांड मौजूद नहीं है, तब भी उसे लिखें: Nibras सही पैक सुझाएगा।
- अगर इंस्टॉलेशन बीच में रुक जाए, तो वही `install` कमांड फिर से चलाएँ; डाउनलोड वहीं से आगे बढ़ेगा और उसकी जाँच होगी।
- `nibras-reload-settings` सेटिंग्स फ़ाइलों में किए गए बदलाव लागू करता है।
- अगर ऐप अचानक बंद हो जाए, तो त्रुटि रिपोर्ट `crash.txt` में सहेजी जाती है, और अगली बार खोलने पर ऐप उसे दिखाने और शेयर करने का विकल्प देता है। GitHub पर समस्या रिपोर्ट करते समय कृपया यह फ़ाइल संलग्न करें।

## 17. अक्सर पूछे जाने वाले सवाल

**क्या Nibras Terminal मुफ़्त है?** हाँ। यह ओपन सोर्स है।

**क्या इसके लिए रूट चाहिए?** नहीं। सब कुछ रूट के बिना चलता है; ऊपर बताए अनुसार सिर्फ़ कुछ सिस्टम-स्तर के काम सीमित हैं।

**ऐप इतना छोटा क्यों है?** इसमें सिर्फ़ Alpine Linux और अनुवाद शामिल हैं। बाकी सब कुछ ज़रूरत पड़ने पर `install` से डाउनलोड होता है।

**क्या यह 32-बिट फ़ोन पर चलता है?** हाँ। एक ही APK arm64 और arm32 दोनों तरह के डिवाइस सपोर्ट करता है।
