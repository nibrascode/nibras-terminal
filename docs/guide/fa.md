# نبراس ترمینال — راهنمای کاربر (فارسی)

[→ بازگشت به README](../../README.md) · [همهٔ زبان‌ها](../../README.md#-guides-in-your-language)

## ۱. نبراس ترمینال چیست؟

نبراس ترمینال یک ترمینال کامل لینوکس برای گوشی‌های اندرویدی است. برنامه مستقیماً با یک ترمینال واقعی باز می‌شود، Alpine Linux بدون هیچ تنظیمی در آن اجرا می‌شود و هر وقت لازم باشد می‌توانید Debian، Ubuntu، Arch، Fedora و Kali را اضافه کنید. این برنامه همچنین یک ویرایشگر کد با پشتیبانی از سرورهای زبان، یک مدیر فایل، یک کلاینت SSH، ابزارهایی برای ساخت و ویرایش فایل‌های APK، ابزارهای رسانه و مجموعهٔ بزرگی از فرمان‌هایی دارد که فقط در نبراس وجود دارند. حجم خود برنامه کوچک می‌ماند، چون ابزارهای سنگین فقط وقتی دانلود می‌شوند که شما بخواهید.

## ۲. نصب و اولین اجرا

1. آخرین فایل APK را از صفحهٔ پروژه در GitHub ‏(Actions ← *Android package* ← artifact) یا از پیوندی که توسعه‌دهنده برایتان فرستاده است دانلود کنید.
2. فایل را باز کنید و وقتی اندروید درخواست کرد، اجازهٔ «نصب برنامه‌های ناشناس» را بدهید.
3. در اولین اجرا، نبراس ترمینال صفحهٔ انتخاب زبان را نشان می‌دهد. هر زبان با نام خودش نوشته شده و زبان گوشی شما از قبل انتخاب شده است. اگر زبان گوشی شما موجود نباشد، انگلیسی استفاده می‌شود.
4. محیط داخلی Alpine Linux به‌طور خودکار آماده می‌شود و ترمینال باز می‌شود.

هر زمان بخواهید می‌توانید زبان را با فرمان `lang` یا از تنظیمات تغییر دهید.

## ۳. مقدمات

- برای باز کردن منوی کناری که نشست‌ها، محیط‌ها، ابزارها و تنظیمات در آن است، از لبهٔ چپ صفحه بکشید یا روی `☰` در ردیف کلیدهای اضافه بزنید.
- برای تغییر نام یا بستن یک نشست، آن را لمس کنید و نگه دارید. برای انتخاب محیط (Alpine، Debian، Ubuntu یا پوستهٔ اندروید)، «نشست جدید» را لمس کنید و نگه دارید.
- ردیف کلیدهای اضافه شامل `ESC`، `TAB`، `CTRL`، `ALT`، کلیدهای جهت‌نما و کلیدهای دیگر است. `CTRL` و `ALT` تا کلید بعدی فشرده می‌مانند.
- دکمهٔ کم کردن صدا مانند `CTRL` و دکمهٔ زیاد کردن صدا به‌عنوان کلید تغییردهندهٔ کلیدهای اضافه عمل می‌کند.
- برای باز کردن منوی همهٔ ابزارهای نبراس `nibras` و برای دیدن فهرست کوتاهی از فرمان‌ها `help` را تایپ کنید.

</div>

```sh
nibras
help
```

## ۴. نصب ابزارها با `install`

ابزارها درون فایل APK نگهداری نمی‌شوند. برای دیدن همهٔ بسته‌ها همراه با توضیح کوتاه `install` و برای افزودن یکی از آن‌ها `install <نام>` را تایپ کنید. برنامه‌هایی که جزو بسته‌های نبراس نیستند با `pkg install <نام>` نصب می‌شوند.

</div>

```sh
install
install python
install video
install dev
pkg install htop
```

## ۵. محیط‌های لینوکس (توزیع‌ها)

Alpine Linux درون برنامه قرار دارد. توزیع‌های دیگر هنگام درخواست دانلود می‌شوند و هرکدام به‌عنوان یک محیط جداگانه اجرا می‌شوند.

</div>

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## ۶. زبان‌های برنامه‌نویسی و `run`

فرمان `run` فایل را از روی پسوندش تشخیص می‌دهد، بار اول ابزار لازم را خودش نصب می‌کند و سپس فایل را اجرا می‌کند. این فرمان با Python، JavaScript، TypeScript، Java، Kotlin، C، C++‎، Go، Rust، PHP، Ruby، Perl، Lua، Dart، R، Julia، Haskell، Elixir، Zig، Nim، Bash، PowerShell و زبان‌های دیگر کار می‌کند. اگر یک پوشه به آن بدهید، نوع پروژه (Cargo، ماژول‌های Go، npm، Gradle، CMake، Makefile و غیره) را خودش تشخیص می‌دهد.

</div>

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## ۷. ویرایشگر کد و LSP

یک فایل را با `edit <فایل>` یا از مدیر فایل باز کنید. ویرایشگر نحو بیش از ۲۵ زبان را رنگی می‌کند، کلیدواژه‌ها و قطعه‌کدها را تکمیل می‌کند، کد را مرتب می‌کند، پیش‌نمایش Markdown، HTML و طرح‌بندی‌های اندروید را نشان می‌دهد و فایل را با دکمهٔ ▶ اجرا می‌کند.

برای تکمیل هوشمند، خط کشیدن زیر خطاها، نمایش اطلاعات و رفتن به تعریف، یک بار سرور زبان را نصب کنید. وقتی سرور در حال اجراست، 🧠 در نوار وضعیت نمایش داده می‌شود.

</div>

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

<div dir="rtl">

برای دیدن مستندات یک واژه، آن را در ویرایشگر لمس کنید و نگه دارید. منوی ⋯ شامل «مشکلات»، «اطلاعات زیر مکان‌نما» و «رفتن به تعریف» است.

## ۸. مدیر فایل

مدیر فایل را از منوی کناری یا با فرمان `files` باز کنید. می‌توانید فایل‌ها را کپی، جابه‌جا، تغییر نام، حذف، فشرده، از حالت فشرده خارج، اشتراک‌گذاری و باز کنید و پس از اجرای `nibras-setup-storage` به حافظهٔ گوشی هم دسترسی دارید.

</div>

```sh
files
nibras-setup-storage
```

## ۹. SSH

صفحهٔ SSH در منوی کناری میزبان‌ها، کلیدها، هدایت پورت‌ها و میزبان‌های واسط (jump host) شما را نگه می‌دارد. Mosh، Telnet و SFTP پشتیبانی می‌شوند. همچنین می‌توانید یک سرور SSH روی گوشی اجرا کنید.

</div>

```sh
ssh user@example.com
nibras-sshd
```

<div dir="rtl">

میزبان‌ها به‌صورت یک فایل `ssh config` صادر و وارد می‌شوند، بنابراین می‌توانید آن‌ها را بدون حساب ابری بین دستگاه‌ها جابه‌جا کنید.

## ۱۰. ابزارهای APK و ویرایشگر منابع

`nibras-apk` برنامه‌های اندروید را روی خود گوشی می‌سازد، باز می‌کند، ویرایش و امضا می‌کند.

</div>

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

<div dir="rtl">

ویرایشگر تصویری منابع (`nibras-apk res`) به شما امکان می‌دهد متن‌های هر زبان را در یک جدول ویرایش کنید، رنگ‌ها را تغییر دهید، آیکون‌ها و تصاویر را از گالری جایگزین کنید و نام برنامه، نام بسته و نسخه را تغییر دهید. سپس با یک لمس، برنامه دوباره ساخته، امضا و نصب می‌شود. قابلیت‌هایی که بررسی مجوز یا محافظت برنامه‌های دیگران را دور می‌زنند عمداً اضافه نشده‌اند.

## ۱۳. فرمان‌های زبان

ترمینال عبارت‌های طبیعی را به چند زبان می‌فهمد و بزرگی یا کوچکی حروف مهم نیست.

</div>

```sh
lang
lang az
az dili yukle
türkçe yükle
تحميل العربية
install lang-fr
lang auto
```

<div dir="rtl">

صفحه‌های عربی، فارسی و اردو از راست به چپ چیده می‌شوند. برای نمایش متن عربی یا فارسی با حروف پیوسته درون ترمینال، از فرمان `rtl` استفاده کنید، برای مثال: `cat note.txt | rtl`.

## ۱۴. قابلیت‌هایی که فقط نبراس دارد

- `ask`، `explain` و `fix` در کار با فرمان‌ها و رفع خطاها به شما کمک می‌کنند.
- `recipes` و `learn` راه‌حل‌های آماده و درس‌های لینوکس دارند.
- `vault` فایل‌های خصوصی را رمزگذاری‌شده نگه می‌دارد و `trash` حذف کردن را امن می‌کند.
- `quran`، `hadith` و `prayer` (همراه با یادآوری) درون برنامه هستند.
- `llm` یک گفت‌وگوی هوش مصنوعی آفلاین را روی گوشی اجرا می‌کند.
- `webterm` این ترمینال را از طریق Wi-Fi در مرورگر رایانه باز می‌کند.
- تقسیم صفحه، پنجرهٔ شناور و دسکتاپ لینوکس (XFCE) درون برنامه کار می‌کنند.

## ۱۵. مجوزها

نبراس ترمینال فقط وقتی مجوزی را درخواست می‌کند که فرمانی به آن نیاز داشته باشد. فرمان‌های دوربین، میکروفون، موقعیت مکانی، مخاطبان و پیامک در اولین استفاده اجازه می‌خواهند. مجوز «نصب برنامه‌های ناشناس» برای نصب فایل‌های APK که خودتان می‌سازید لازم است. مجوز «زنگ‌های هشدار و یادآوری‌ها» برای یادآوری نماز لازم است. دسترسی به اعلان‌ها، «تغییر تنظیمات سیستم» و جفت‌سازی اشکال‌زدایی بی‌سیم (`nibras-adb pair`) اختیاری‌اند و فقط فرمان‌هایی که به آن‌ها اشاره می‌کنند از آن‌ها استفاده می‌کنند. بدون دسترسی روت، اشتراک‌گذاری فایل ویندوز به‌جای پورت 445 از پورت 4445 استفاده می‌کند و ابزارهای مبتنی بر FUSE مانند `sshfs` در دسترس نیستند.

## ۱۶. رفع اشکال

- اگر فرمانی پیدا نشد، باز هم آن را تایپ کنید؛ نبراس بستهٔ مناسب را پیشنهاد می‌دهد.
- اگر نصب متوقف شد، همان فرمان `install` را دوباره اجرا کنید؛ دانلود از همان جا ادامه پیدا می‌کند و بررسی می‌شود.
- `nibras-reload-settings` تغییرات فایل‌های تنظیمات را اعمال می‌کند.
- اگر برنامه ناگهان بسته شود، گزارش خطا در فایل `crash.txt` ذخیره می‌شود و در اجرای بعدی پیشنهاد نمایش و اشتراک‌گذاری آن داده می‌شود. لطفاً هنگام گزارش مشکل در GitHub این فایل را پیوست کنید.

## ۱۷. پرسش‌های متداول

**آیا نبراس ترمینال رایگان است؟** بله. این برنامه متن‌باز است.

**آیا به روت نیاز دارد؟** خیر. همه چیز بدون روت کار می‌کند؛ فقط چند کار در سطح سیستم، همان‌طور که در بالا گفته شد، محدود است.

**چرا حجم برنامه این‌قدر کم است؟** فقط Alpine Linux و ترجمه‌ها درون آن هستند. بقیهٔ چیزها هر وقت لازم باشد با `install` دانلود می‌شوند.

**آیا روی گوشی‌های ۳۲ بیتی کار می‌کند؟** بله. یک فایل APK از هر دو نوع دستگاه arm64 و arm32 پشتیبانی می‌کند.
