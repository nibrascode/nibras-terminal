# Nibras Terminal — ব্যবহার নির্দেশিকা (বাংলা)

[← README-তে ফিরে যান](../../README.md) · [সব ভাষা](../../README.md#-guides-in-your-language)

## 1. Nibras Terminal কী?

Nibras Terminal হলো Android ফোনের জন্য একটি পূর্ণাঙ্গ Linux টার্মিনাল। অ্যাপটি খুললেই সরাসরি একটি আসল টার্মিনাল দেখা যায়, এতে Alpine Linux কোনো সেটআপ ছাড়াই চলে, আর প্রয়োজন হলে যেকোনো সময় Debian, Ubuntu, Arch, Fedora ও Kali যোগ করা যায়। এতে আরও আছে ল্যাঙ্গুয়েজ সার্ভার সমর্থিত কোড এডিটর, ফাইল ম্যানেজার, SSH ক্লায়েন্ট, APK ফাইল তৈরি ও পরিবর্তনের টুল, মিডিয়া টুল এবং এমন অনেক কমান্ড যা শুধু Nibras-এই আছে। ভারী টুলগুলো কেবল আপনি চাইলে ডাউনলোড হয় বলে অ্যাপটি নিজে ছোট থাকে।

## 2. ইনস্টল ও প্রথমবার চালু করা

1. সরাসরি APK ডাউনলোড করুন: https://github.com/nibrascode/nibras-terminal/releases/download/v1.0.0/nibras-terminal-1.0.0.apk
2. ফাইলটি খুলুন এবং Android জানতে চাইলে "অজানা অ্যাপ ইনস্টল করুন" অনুমতি দিন।
3. প্রথমবার চালু করলে Nibras Terminal একটি ভাষা বাছাইয়ের পর্দা দেখায়। প্রতিটি ভাষা তার নিজের নামে লেখা থাকে এবং আপনার ফোনের ভাষা আগে থেকেই নির্বাচিত থাকে। আপনার ফোনের ভাষা না থাকলে ইংরেজি ব্যবহার করা হয়।
4. ভেতরের Alpine Linux পরিবেশ স্বয়ংক্রিয়ভাবে প্রস্তুত হয় এবং টার্মিনাল খুলে যায়।

`lang` কমান্ড দিয়ে বা সেটিংস থেকে যেকোনো সময় ভাষা বদলাতে পারবেন।

## 3. মৌলিক বিষয়

- সেশন, পরিবেশ, টুল ও সেটিংস থাকা পাশের মেনু খুলতে পর্দার বাঁ প্রান্ত থেকে সোয়াইপ করুন, অথবা অতিরিক্ত কী-এর সারিতে `☰` চাপুন।
- কোনো সেশনের নাম বদলাতে বা বন্ধ করতে সেটি চেপে ধরে রাখুন। পরিবেশ (Alpine, Debian, Ubuntu বা Android শেল) বেছে নিতে "নতুন সেশন" চেপে ধরে রাখুন।
- অতিরিক্ত কী-এর সারিতে আছে `ESC`, `TAB`, `CTRL`, `ALT`, তীর-চিহ্নের কী এবং আরও অনেক কিছু। `CTRL` ও `ALT` পরের কী চাপা পর্যন্ত চাপা অবস্থায় থাকে।
- ভলিউম কমানোর বোতাম `CTRL` হিসেবে এবং ভলিউম বাড়ানোর বোতাম অতিরিক্ত কী-এর মডিফায়ার হিসেবে কাজ করে।
- সব Nibras টুলের মেনু খুলতে `nibras` লিখুন, আর কমান্ডের ছোট তালিকা দেখতে `help` লিখুন।

```sh
nibras
help
```

## 4. `install` দিয়ে টুল ইনস্টল করা

টুলগুলো APK-এর ভেতরে রাখা হয় না। সব প্যাক সংক্ষিপ্ত বিবরণসহ দেখতে `install` লিখুন, আর কোনোটি যোগ করতে `install <নাম>` লিখুন। যেসব প্রোগ্রাম Nibras প্যাক নয়, সেগুলো `pkg install <নাম>` দিয়ে ইনস্টল হয়।

```sh
install
install python
install video
install dev
pkg install htop
```

## 5. Linux পরিবেশ (ডিস্ট্রিবিউশন)

Alpine Linux অ্যাপের মধ্যেই আছে। অন্যান্য ডিস্ট্রিবিউশন চাইলে ডাউনলোড হয়, এবং প্রতিটি আলাদা পরিবেশ হিসেবে চলে।

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## 6. প্রোগ্রামিং ভাষা ও `run`

`run` কমান্ড ফাইলের এক্সটেনশন দেখে ফাইল চিনে নেয়, প্রথমবার প্রয়োজনীয় টুল নিজেই ইনস্টল করে এবং তারপর ফাইলটি চালায়। এটি Python, JavaScript, TypeScript, Java, Kotlin, C, C++, Go, Rust, PHP, Ruby, Perl, Lua, Dart, R, Julia, Haskell, Elixir, Zig, Nim, Bash, PowerShell সহ আরও অনেক ভাষায় কাজ করে। একটি ফোল্ডার দিলে এটি প্রজেক্টের ধরন (Cargo, Go মডিউল, npm, Gradle, CMake, Makefile ইত্যাদি) নিজেই শনাক্ত করে।

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## 7. কোড এডিটর ও LSP

`edit <ফাইল>` দিয়ে বা ফাইল ম্যানেজার থেকে ফাইল খুলুন। এডিটরটি ২৫টির বেশি ভাষার সিনট্যাক্স রঙিন করে, কীওয়ার্ড ও স্নিপেট সম্পূর্ণ করে, কোড সাজিয়ে দেয়, Markdown, HTML ও Android লেআউটের প্রিভিউ দেখায় এবং ▶ বোতাম দিয়ে ফাইল চালায়।

স্মার্ট কমপ্লিশন, ভুলের নিচে দাগ, হোভার তথ্য এবং সংজ্ঞায় যাওয়ার সুবিধার জন্য একবার একটি ল্যাঙ্গুয়েজ সার্ভার ইনস্টল করুন। সার্ভার চালু থাকলে স্ট্যাটাস বারে 🧠 দেখা যায়।

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

কোনো শব্দের ডকুমেন্টেশন দেখতে এডিটরে শব্দটি চেপে ধরে রাখুন। ⋯ মেনুতে "সমস্যা", "কার্সরের তথ্য" এবং "সংজ্ঞায় যান" আছে।

## 8. ফাইল ম্যানেজার

পাশের মেনু থেকে বা `files` কমান্ড দিয়ে ফাইল ম্যানেজার খুলুন। আপনি ফাইল কপি, সরানো, নাম বদল, মুছে ফেলা, কমপ্রেস, এক্সট্র্যাক্ট, শেয়ার ও খুলতে পারেন, এবং `nibras-setup-storage` চালানোর পর ফোনের স্টোরেজেও যেতে পারেন।

```sh
files
nibras-setup-storage
```

## 9. SSH

পাশের মেনুর SSH পর্দা আপনার হোস্ট, কী, পোর্ট ফরওয়ার্ড ও জাম্প হোস্ট সংরক্ষণ করে। Mosh, Telnet ও SFTP সমর্থিত। আপনি ফোনে একটি SSH সার্ভারও চালাতে পারেন।

```sh
ssh user@example.com
nibras-sshd
```

হোস্টগুলো একটি `ssh config` ফাইল হিসেবে এক্সপোর্ট ও ইমপোর্ট হয়, তাই ক্লাউড অ্যাকাউন্ট ছাড়াই এগুলো এক ডিভাইস থেকে অন্য ডিভাইসে নেওয়া যায়।

## 10. APK টুল ও রিসোর্স এডিটর

`nibras-apk` ফোনেই Android অ্যাপ তৈরি করে, খুলে দেখে, সম্পাদনা করে ও সাইন করে।

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

ভিজ্যুয়াল রিসোর্স এডিটর (`nibras-apk res`) দিয়ে প্রতিটি ভাষার লেখা একটি টেবিলে সম্পাদনা করা, রং বদলানো, গ্যালারি থেকে আইকন ও ছবি বদলানো এবং অ্যাপের নাম, প্যাকেজের নাম ও সংস্করণ পরিবর্তন করা যায়। এরপর এক ট্যাপে অ্যাপটি আবার তৈরি হয়, সাইন হয় এবং ইনস্টল হয়। অন্যের অ্যাপের লাইসেন্স যাচাই বা সুরক্ষা ভাঙার মতো ফিচার ইচ্ছাকৃতভাবে রাখা হয়নি।

## 11. ভিডিও, অডিও, ডাউনলোড ও ডকুমেন্ট

```sh
video merge a.mp4 b.mp4
video cut in.mp4 00:01:00 00:02:30
video compress in.mp4
audio convert in.wav out.mp3
image resize photo.jpg 50%
pdf merge a.pdf b.pdf
download https://example.com/video
```

`download` একটি লিংক থেকে ভিডিও, গান ও ফাইল সংরক্ষণ করে। অনুগ্রহ করে শুধু সেই কনটেন্টই ডাউনলোড করুন যা সংরক্ষণের অধিকার আপনার আছে। `media` কমান্ড একই কাজের জন্য একটি ভিজ্যুয়াল পর্দা খোলে।

## 12. সাজসজ্জা ও রঙিন লেখা


`theme list`, `prompt list`, `font list` ও `color list` সব বিকল্প দেখায়। `customize` সব সেটিংসসহ একটি মেনু খোলে, আর `reset-look` সবকিছু ডিফল্টে ফিরিয়ে দেয়। সেটিংস `~/.nibras/`-এ সংরক্ষিত হয়।

## 14. যেসব ফিচার শুধু Nibras-এ আছে

- `ask`, `explain` ও `fix` কমান্ড ও ভুল নিয়ে আপনাকে সাহায্য করে।
- `recipes` ও `learn`-এ আছে তৈরি সমাধান ও Linux-এর পাঠ।
- `vault` ব্যক্তিগত ফাইল এনক্রিপ্ট করে রাখে, আর `trash` মুছে ফেলাকে নিরাপদ করে।
- `quran`, `hadith` ও `prayer` (রিমাইন্ডারসহ) অ্যাপে অন্তর্ভুক্ত।
- `llm` ফোনে অফলাইন AI চ্যাট চালায়।
- `webterm` এই টার্মিনালটি Wi-Fi-এর মাধ্যমে কম্পিউটারের ব্রাউজারে খোলে।
- স্প্লিট স্ক্রিন, ভাসমান উইন্ডো এবং Linux ডেস্কটপ (XFCE) অ্যাপের ভেতরেই কাজ করে।
- `scripts` স্ক্রিপ্ট স্টোর খোলে, যেখানে আপনি তৈরি স্ক্রিপ্ট দেখতে, পড়তে, ইনস্টল করতে ও চালাতে পারেন।
- `remote` এই টার্মিনালটি একই Wi-Fi-তে থাকা কম্পিউটারের ব্রাউজারে খোলে। একবার ব্যবহারযোগ্য লিংকটি QR কোড হিসেবেও দেখানো হয়।
- `backup drive` আপনার হোস্ট ও সেটিংস আপনার নিজের পাসফ্রেজ দিয়ে এনক্রিপ্ট করে Google Drive বা যেকোনো ফোল্ডারে সংরক্ষণ করে। `restore drive` সেগুলো ফিরিয়ে আনে।
- `learn` ইন্টারঅ্যাক্টিভ পাঠ শুরু করে: আপনি আসল কমান্ড লেখেন এবং সেগুলো স্বয়ংক্রিয়ভাবে যাচাই হয়।
- হোম-স্ক্রিন উইজেট আপনার প্রিয় কমান্ড এক ট্যাপে চালায় এবং সার্ভারের অবস্থা ও নামাজের সময় দেখায়।

## 15. অনুমতি

Nibras Terminal কেবল তখনই অনুমতি চায় যখন কোনো কমান্ডের তা দরকার হয়। ক্যামেরা, মাইক্রোফোন, লোকেশন, কন্টাক্ট ও SMS কমান্ড প্রথমবার ব্যবহারের সময় অনুমতি চায়। আপনার তৈরি APK ফাইল ইনস্টল করতে "অজানা অ্যাপ ইনস্টল করুন" অনুমতি লাগে। নামাজের রিমাইন্ডারের জন্য "অ্যালার্ম ও রিমাইন্ডার" অনুমতি লাগে। নোটিফিকেশন অ্যাক্সেস, "সিস্টেম সেটিংস পরিবর্তন" এবং ওয়্যারলেস ডিবাগিং পেয়ারিং (`nibras-adb pair`) ঐচ্ছিক, এবং শুধু যেসব কমান্ডে এগুলোর উল্লেখ আছে সেগুলোই এগুলো ব্যবহার করে। রুট ছাড়া Windows ফাইল শেয়ারিং 445-এর বদলে 4445 পোর্ট ব্যবহার করে, এবং `sshfs`-এর মতো FUSE-ভিত্তিক টুল পাওয়া যায় না।

## 16. সমস্যা সমাধান

- কোনো কমান্ড না থাকলেও সেটি লিখুন: Nibras সঠিক প্যাকের পরামর্শ দেবে।
- ইনস্টল মাঝপথে থেমে গেলে একই `install` কমান্ড আবার চালান; ডাউনলোড যেখানে থেমেছিল সেখান থেকে চলবে এবং যাচাই করা হবে।
- `nibras-reload-settings` সেটিংস ফাইলে করা পরিবর্তনগুলো প্রয়োগ করে।
- অ্যাপ হঠাৎ বন্ধ হয়ে গেলে ত্রুটির রিপোর্ট `crash.txt`-এ সংরক্ষিত হয়, এবং পরেরবার চালু করলে অ্যাপ সেটি দেখানো ও শেয়ার করার প্রস্তাব দেয়। GitHub-এ সমস্যা জানানোর সময় অনুগ্রহ করে এই ফাইলটি সংযুক্ত করুন।

## 17. সচরাচর জিজ্ঞাসা

**Nibras Terminal কি বিনামূল্যে?** হ্যাঁ। এটি ওপেন সোর্স।

**এর জন্য কি রুট লাগে?** না। সবকিছু রুট ছাড়াই চলে; ওপরে যেমন বলা হয়েছে, শুধু কয়েকটি সিস্টেম-স্তরের কাজ সীমিত।

**অ্যাপটি এত ছোট কেন?** এতে শুধু Alpine Linux ও অনুবাদ আছে। বাকি সবকিছু প্রয়োজনের সময় `install` দিয়ে ডাউনলোড হয়।

**এটি কি ৩২-বিট ফোনে চলে?** হ্যাঁ। একটি APK-ই arm64 ও arm32 দুই ধরনের ডিভাইস সমর্থন করে।
