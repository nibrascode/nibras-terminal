# Nibras Terminal — Руководство пользователя (Русский)

[← Назад к README](../../README.md) · [Все языки](../../README.md#-guides-in-your-language)

## 1. Что такое Nibras Terminal?

Nibras Terminal — это полноценный терминал Linux для телефонов на Android. Приложение сразу открывает настоящий терминал, Alpine Linux работает «из коробки», а Debian, Ubuntu, Arch, Fedora и Kali можно добавить в любой момент. В приложении есть редактор кода с поддержкой языковых серверов, файловый менеджер, SSH-клиент, инструменты для сборки и изменения APK, медиаинструменты и множество команд, которые есть только в Nibras. Само приложение остаётся небольшим, потому что тяжёлые инструменты загружаются только по вашему запросу.

## 2. Установка и первый запуск

1. Скачайте последний APK со страницы проекта на GitHub (Actions → *Android package* → artifact) или по ссылке, которую прислал разработчик.
2. Откройте файл и разрешите «Установку неизвестных приложений», когда Android попросит об этом.
3. При первом запуске Nibras Terminal показывает экран выбора языка. Все языки указаны на своём собственном языке, а язык вашего телефона уже выбран. Если языка вашего телефона нет в списке, используется английский.
4. Встроенная среда Alpine Linux подготавливается автоматически, после чего открывается терминал.

Язык можно сменить в любое время командой `lang` или в настройках.

## 3. Основы

- Чтобы открыть меню с сессиями, средами, инструментами и настройками, проведите пальцем от левого края экрана или нажмите `☰` в ряду дополнительных клавиш.
- Нажмите и удерживайте сессию, чтобы переименовать или закрыть её. Нажмите и удерживайте «Новая сессия», чтобы выбрать среду (Alpine, Debian, Ubuntu или оболочку Android).
- В ряду дополнительных клавиш есть `ESC`, `TAB`, `CTRL`, `ALT`, стрелки и другие клавиши. `CTRL` и `ALT` остаются нажатыми до следующей клавиши.
- Клавиша уменьшения громкости работает как `CTRL`, а клавиша увеличения громкости — как модификатор дополнительных клавиш.
- Введите `nibras`, чтобы открыть меню всех инструментов Nibras, и `help`, чтобы увидеть краткий список команд.

```sh
nibras
help
```

## 4. Установка инструментов командой `install`

Инструменты не хранятся внутри APK. Введите `install`, чтобы увидеть все пакеты с кратким описанием, и `install <имя>`, чтобы добавить нужный. Программы, которые не являются пакетами Nibras, устанавливаются командой `pkg install <имя>`.

```sh
install
install python
install video
install dev
pkg install htop
```

## 5. Среды Linux (дистрибутивы)

Alpine Linux встроен в приложение. Другие дистрибутивы загружаются по запросу, и каждый из них работает как отдельная среда.

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## 6. Языки программирования и `run`

Команда `run` определяет файл по расширению, при первом запуске сама устанавливает нужный инструмент и запускает файл. Поддерживаются Python, JavaScript, TypeScript, Java, Kotlin, C, C++, Go, Rust, PHP, Ruby, Perl, Lua, Dart, R, Julia, Haskell, Elixir, Zig, Nim, Bash, PowerShell и другие языки. Если указать папку, команда сама определит тип проекта (Cargo, модули Go, npm, Gradle, CMake, Makefile и другие).

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## 7. Редактор кода и LSP

Откройте файл командой `edit <файл>` или из файлового менеджера. Редактор подсвечивает синтаксис более чем 25 языков, дополняет ключевые слова и шаблоны, форматирует код, показывает предпросмотр Markdown, HTML и разметки Android, а кнопка ▶ запускает файл.

Для умного автодополнения, подчёркивания ошибок, всплывающих подсказок и перехода к определению один раз установите языковой сервер. Когда сервер работает, в строке состояния отображается 🧠.

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

Нажмите и удерживайте слово в редакторе, чтобы увидеть его описание. В меню ⋯ есть пункты «Проблемы», «Справка под курсором» и «Перейти к определению».

## 8. Файловый менеджер

Откройте файловый менеджер из бокового меню или командой `files`. Вы можете копировать, перемещать, переименовывать, удалять, сжимать, распаковывать, отправлять и открывать файлы, а после команды `nibras-setup-storage` получаете доступ и к памяти телефона.

```sh
files
nibras-setup-storage
```

## 9. SSH

Экран SSH в боковом меню хранит ваши хосты, ключи, перенаправления портов и промежуточные хосты (jump host). Поддерживаются Mosh, Telnet и SFTP. На телефоне также можно запустить SSH-сервер.

```sh
ssh user@example.com
nibras-sshd
```

Хосты экспортируются и импортируются в виде файла `ssh config`, поэтому их можно переносить между устройствами без облачной учётной записи.

## 10. Инструменты APK и редактор ресурсов

`nibras-apk` собирает, разбирает, изменяет и подписывает приложения Android прямо на телефоне.

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

Визуальный редактор ресурсов (`nibras-apk res`) позволяет редактировать строки для каждого языка в таблице, менять цвета, заменять значки и изображения из галереи, а также изменять название приложения, имя пакета и версию. Затем одним нажатием приложение пересобирается, подписывается и устанавливается. Функции, которые взламывают проверку лицензии или защиту чужих приложений, намеренно не добавлены.

## 11. Видео, аудио, загрузки и документы

```sh
video merge a.mp4 b.mp4
video cut in.mp4 00:01:00 00:02:30
video compress in.mp4
audio convert in.wav out.mp3
image resize photo.jpg 50%
pdf merge a.pdf b.pdf
download https://example.com/video
media
```

Команда `download` сохраняет видео, музыку и файлы по ссылке. Пожалуйста, скачивайте только тот контент, который вы имеете право сохранять. Команда `media` открывает визуальный экран для тех же задач.

## 12. Настройка внешнего вида и цветной текст

```sh
color bold red "Hello"
color rainbow "Nibras Terminal"
echo "Done" | color green
banner Nibras rainbow
theme dracula
theme custom #1e1e2e #cdd6f4
font jetbrains-mono
font size 16
cursor bar blink on
wallpaper ~/storage/dcim/photo.jpg
prompt powerline
keys dev
customize
```

`theme list`, `prompt list`, `font list` и `color list` показывают все варианты. `customize` открывает одно меню со всеми настройками, а `reset-look` возвращает всё к значениям по умолчанию. Настройки хранятся в `~/.nibras/`.

## 13. Языковые команды

Терминал понимает естественные фразы на нескольких языках, а регистр букв не важен.

```sh
lang
lang az
az dili yukle
türkçe yükle
تحميل العربية
install lang-fr
lang auto
```

Экраны на арабском, персидском и урду располагаются справа налево. Чтобы показать арабский текст в терминале со связанными буквами, используйте команду `rtl`, например: `cat note.txt | rtl`.

## 14. Возможности, которые есть только в Nibras

- `ask`, `explain` и `fix` помогают с командами и ошибками.
- `recipes` и `learn` содержат готовые решения и уроки по Linux.
- `vault` хранит личные файлы в зашифрованном виде, а `trash` делает удаление безопасным.
- `quran`, `hadith` и `prayer` с напоминаниями встроены в приложение.
- `llm` запускает офлайн-чат с ИИ прямо на телефоне.
- `webterm` открывает этот терминал в браузере компьютера по Wi-Fi.
- Разделение экрана, плавающее окно и рабочий стол Linux (XFCE) работают внутри приложения.

## 15. Разрешения

Nibras Terminal запрашивает разрешение только тогда, когда оно нужно команде. Команды камеры, микрофона, местоположения, контактов и SMS спрашивают разрешение при первом использовании. Разрешение «Установка неизвестных приложений» нужно для установки собранных вами APK. Разрешение «Будильники и напоминания» нужно для напоминаний о намазе. Доступ к уведомлениям, «Изменение системных настроек» и сопряжение для отладки по Wi-Fi (`nibras-adb pair`) необязательны и используются только командами, которые о них упоминают. Без root общий доступ к файлам для Windows использует порт 4445 вместо 445, а инструменты на основе FUSE, такие как `sshfs`, недоступны.

## 16. Решение проблем

- Если команда не найдена, всё равно введите её: Nibras подскажет нужный пакет.
- Если установка прервалась, снова выполните ту же команду `install`; загрузка продолжится и будет проверена.
- Команда `nibras-reload-settings` применяет изменения, внесённые в файлы настроек.
- Если приложение неожиданно закрылось, отчёт об ошибке сохраняется в файле `crash.txt`, и при следующем запуске приложение предложит показать его и поделиться им. Пожалуйста, прикладывайте этот файл, когда сообщаете о проблеме на GitHub.

## 17. Часто задаваемые вопросы

**Nibras Terminal бесплатный?** Да. Это приложение с открытым исходным кодом.

**Нужен ли root?** Нет. Всё работает без root; ограничены лишь несколько системных задач, описанных выше.

**Почему приложение такое маленькое?** Внутри есть только Alpine Linux и переводы. Всё остальное загружается командой `install`, когда это нужно.

**Работает ли оно на 32-битных телефонах?** Да. Один APK поддерживает устройства и arm64, и arm32.
