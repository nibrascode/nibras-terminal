# نبراس ٹرمینل — صارف گائیڈ (اردو)

[→ README پر واپس جائیں](../../README.md) · [تمام زبانیں](../../README.md#-guides-in-your-language)

## 1. نبراس ٹرمینل کیا ہے؟

نبراس ٹرمینل اینڈرائیڈ فونز کے لیے ایک مکمل لینکس ٹرمینل ہے۔ ایپ سیدھا ایک حقیقی ٹرمینل میں کھلتی ہے، اس میں Alpine Linux بغیر کسی سیٹ اپ کے چلتا ہے، اور ضرورت پڑنے پر آپ Debian، Ubuntu، Arch، Fedora اور Kali شامل کر سکتے ہیں۔ اس میں لینگویج سرور کی سہولت والا کوڈ ایڈیٹر، فائل مینیجر، SSH کلائنٹ، APK فائلیں بنانے اور ان میں تبدیلی کرنے کے ٹولز، میڈیا ٹولز اور ایسی بہت سی کمانڈز بھی موجود ہیں جو صرف نبراس میں ہیں۔ ایپ خود چھوٹی رہتی ہے کیونکہ بھاری ٹولز صرف اسی وقت ڈاؤن لوڈ ہوتے ہیں جب آپ انہیں طلب کریں۔

## 2. انسٹالیشن اور پہلی بار کھولنا

1. APK براہ راست ڈاؤن لوڈ کریں: https://github.com/nibrascode/nibras-terminal/releases/download/v1.0.0/nibras-terminal-1.0.0.apk
2. فائل کھولیں اور جب اینڈرائیڈ پوچھے تو "نامعلوم ایپس انسٹال کریں" کی اجازت دیں۔
3. پہلی بار کھولنے پر نبراس ٹرمینل زبان منتخب کرنے کی اسکرین دکھاتا ہے۔ ہر زبان اپنے نام سے لکھی ہوتی ہے اور آپ کے فون کی زبان پہلے سے منتخب ہوتی ہے۔ اگر آپ کے فون کی زبان دستیاب نہ ہو تو انگریزی استعمال ہوتی ہے۔
4. اندرونی Alpine Linux ماحول خود بخود تیار ہو جاتا ہے اور ٹرمینل کھل جاتا ہے۔

آپ کسی بھی وقت `lang` کمانڈ سے یا سیٹنگز میں جا کر زبان بدل سکتے ہیں۔

## 3. بنیادی باتیں

- سیشنز، ماحول، ٹولز اور سیٹنگز والا مینو کھولنے کے لیے اسکرین کے بائیں کنارے سے سوائپ کریں یا اضافی کیز کی قطار میں `☰` پر ٹیپ کریں۔
- کسی سیشن کا نام بدلنے یا اسے بند کرنے کے لیے اسے دبا کر رکھیں۔ ماحول (Alpine، Debian، Ubuntu یا اینڈرائیڈ شیل) منتخب کرنے کے لیے "نیا سیشن" کو دبا کر رکھیں۔
- اضافی کیز کی قطار میں `ESC`، `TAB`، `CTRL`، `ALT`، تیر والی کیز اور مزید کیز موجود ہیں۔ `CTRL` اور `ALT` اگلی کی تک دبی رہتی ہیں۔
- آواز کم کرنے والا بٹن `CTRL` کا کام کرتا ہے اور آواز بڑھانے والا بٹن اضافی کیز کے موڈیفائر کا کام کرتا ہے۔
- نبراس کے تمام ٹولز کا مینو کھولنے کے لیے `nibras` اور کمانڈز کی مختصر فہرست کے لیے `help` لکھیں۔

</div>

```sh
nibras
help
```

## 4. `install` سے ٹولز انسٹال کرنا

ٹولز APK کے اندر محفوظ نہیں ہوتے۔ تمام پیکس کو مختصر وضاحت کے ساتھ دیکھنے کے لیے `install` اور کوئی پیک شامل کرنے کے لیے `install <نام>` لکھیں۔ جو پروگرام نبراس پیک نہیں ہیں وہ `pkg install <نام>` سے انسٹال ہوتے ہیں۔

</div>

```sh
install
install python
install video
install dev
pkg install htop
```

## 5. لینکس ماحول (ڈسٹری بیوشنز)

Alpine Linux ایپ میں شامل ہے۔ دیگر ڈسٹری بیوشنز درخواست پر ڈاؤن لوڈ ہوتی ہیں اور ہر ایک الگ ماحول کے طور پر چلتی ہے۔

</div>

```sh
install debian
install ubuntu
install arch
install fedora
install kali
proot-distro list
```

## 6. پروگرامنگ زبانیں اور `run`

`run` کمانڈ فائل کو اس کی ایکسٹینشن سے پہچانتی ہے، پہلی بار ضروری ٹول خود انسٹال کرتی ہے اور پھر فائل چلاتی ہے۔ یہ Python، JavaScript، TypeScript، Java، Kotlin، C، C++‎، Go، Rust، PHP، Ruby، Perl، Lua، Dart، R، Julia، Haskell، Elixir، Zig، Nim، Bash، PowerShell اور دیگر زبانوں کے ساتھ کام کرتی ہے۔ اگر آپ اسے کوئی فولڈر دیں تو یہ پروجیکٹ کی قسم (Cargo، Go ماڈیولز، npm، Gradle، CMake، Makefile وغیرہ) خود پہچان لیتی ہے۔

</div>

```sh
run hello.py
run main.c
run app.ts
run .
install typescript
install zig
```

## 7. کوڈ ایڈیٹر اور LSP

کوئی فائل `edit <فائل>` سے یا فائل مینیجر سے کھولیں۔ ایڈیٹر 25 سے زیادہ زبانوں کے سنٹیکس کو رنگین کرتا ہے، کلیدی الفاظ اور کوڈ کے ٹکڑے مکمل کرتا ہے، کوڈ کو فارمیٹ کرتا ہے، Markdown، HTML اور اینڈرائیڈ لے آؤٹس کا پیش منظر دکھاتا ہے اور ▶ بٹن سے فائل چلاتا ہے۔

اسمارٹ تکمیل، غلطیوں کو نشان زد کرنے، معلومات دکھانے اور تعریف تک جانے کے لیے ایک بار لینگویج سرور انسٹال کریں۔ جب سرور چل رہا ہو تو اسٹیٹس بار میں 🧠 نظر آتا ہے۔

</div>

```sh
edit main.py
install lsp-python
install lsp-java
install lsp-kotlin
install lsp-all
```

<div dir="rtl">

کسی لفظ کی دستاویزات دیکھنے کے لیے ایڈیٹر میں اسے دبا کر رکھیں۔ ⋯ مینو میں "مسائل"، "کرسر پر معلومات" اور "تعریف پر جائیں" موجود ہیں۔

## 8. فائل مینیجر

فائل مینیجر کو سائیڈ مینو سے یا `files` کمانڈ سے کھولیں۔ آپ فائلیں کاپی، منتقل، نام تبدیل، حذف، کمپریس، ایکسٹریکٹ، شیئر اور کھول سکتے ہیں، اور `nibras-setup-storage` چلانے کے بعد فون کی اسٹوریج تک بھی رسائی حاصل کر سکتے ہیں۔

</div>

```sh
files
nibras-setup-storage
```

<div dir="rtl">

## 9. SSH

سائیڈ مینو میں SSH اسکرین آپ کے ہوسٹس، کیز، پورٹ فارورڈز اور جمپ ہوسٹس محفوظ رکھتی ہے۔ Mosh، Telnet اور SFTP کی سہولت موجود ہے۔ آپ فون پر SSH سرور بھی چلا سکتے ہیں۔

</div>

```sh
ssh user@example.com
nibras-sshd
```

<div dir="rtl">

ہوسٹس ایک `ssh config` فائل کی صورت میں ایکسپورٹ اور امپورٹ ہوتے ہیں، اس لیے آپ انہیں کلاؤڈ اکاؤنٹ کے بغیر ایک ڈیوائس سے دوسری ڈیوائس پر منتقل کر سکتے ہیں۔

## 10. APK ٹولز اور ریسورس ایڈیٹر

`nibras-apk` فون پر ہی اینڈرائیڈ ایپس بناتا ہے، کھولتا ہے، ان میں ترمیم کرتا ہے اور انہیں سائن کرتا ہے۔

</div>

```sh
nibras-apk wizard
nibras-apk new MyApp com.example.myapp --template kotlin
nibras-apk run MyApp
nibras-apk decompile app.apk
nibras-apk res app.apk
nibras-apk merge app.apks
nibras-apk install-split app.xapk
nibras-apk apps
nibras-apk extract com.example.app
```

<div dir="rtl">

بصری ریسورس ایڈیٹر (`nibras-apk res`) آپ کو ہر زبان کے متن ایک جدول میں ترمیم کرنے، رنگ بدلنے، گیلری سے آئیکنز اور تصاویر تبدیل کرنے، اور ایپ کا نام، پیکیج کا نام اور ورژن بدلنے کی سہولت دیتا ہے۔ پھر ایک ٹیپ سے ایپ دوبارہ بنتی ہے، سائن ہوتی ہے اور انسٹال ہو جاتی ہے۔ دوسروں کی ایپس کی لائسنس جانچ یا حفاظت توڑنے والی خصوصیات جان بوجھ کر شامل نہیں کی گئیں۔

## 14. وہ خصوصیات جو صرف نبراس میں ہیں

- `ask`، `explain` اور `fix` کمانڈز اور غلطیوں میں آپ کی مدد کرتی ہیں۔
- `recipes` اور `learn` میں تیار حل اور لینکس کے اسباق موجود ہیں۔
- `vault` نجی فائلوں کو خفیہ کاری کے ساتھ محفوظ رکھتا ہے، اور `trash` حذف کرنے کو محفوظ بناتا ہے۔
- `quran`، `hadith` اور `prayer` (یاد دہانیوں کے ساتھ) ایپ میں شامل ہیں۔
- `llm` فون پر آف لائن AI چیٹ چلاتا ہے۔
- `webterm` اس ٹرمینل کو Wi-Fi کے ذریعے کمپیوٹر کے براؤزر میں کھولتا ہے۔
- اسپلٹ اسکرین، تیرتی ونڈو اور لینکس ڈیسک ٹاپ (XFCE) ایپ کے اندر کام کرتے ہیں۔
- `scripts` اسکرپٹ اسٹور کھولتا ہے، جہاں آپ تیار اسکرپٹس دیکھ، پڑھ، انسٹال اور چلا سکتے ہیں۔
- `remote` اس ٹرمینل کو اسی Wi-Fi پر موجود کمپیوٹر کے براؤزر میں کھولتا ہے۔ ایک بار استعمال ہونے والا لنک QR کوڈ کی صورت میں بھی دکھایا جاتا ہے۔
- `backup drive` آپ کے ہوسٹس اور سیٹنگز کو آپ کے اپنے پاس فریز سے خفیہ کر کے Google Drive یا کسی بھی فولڈر میں محفوظ کرتا ہے۔ `restore drive` انہیں واپس لاتا ہے۔
- `learn` انٹرایکٹو اسباق شروع کرتا ہے: آپ اصل کمانڈز لکھتے ہیں اور وہ خود بخود جانچی جاتی ہیں۔
- ہوم اسکرین ویجیٹس آپ کی پسندیدہ کمانڈز ایک ٹچ سے چلاتے ہیں اور سرورز کی حالت اور نماز کے اوقات دکھاتے ہیں۔

## 15. اجازتیں

نبراس ٹرمینل صرف اسی وقت کوئی اجازت مانگتا ہے جب کسی کمانڈ کو اس کی ضرورت ہو۔ کیمرہ، مائیکروفون، مقام، رابطے اور SMS کی کمانڈز پہلی بار استعمال پر اجازت مانگتی ہیں۔ اپنی بنائی ہوئی APK فائلیں انسٹال کرنے کے لیے "نامعلوم ایپس انسٹال کریں" کی اجازت درکار ہے۔ نماز کی یاد دہانیوں کے لیے "الارمز اور یاد دہانیاں" کی اجازت درکار ہے۔ اطلاعات تک رسائی، "سسٹم سیٹنگز میں ترمیم" اور وائرلیس ڈیبگنگ پیئرنگ (`nibras-adb pair`) اختیاری ہیں اور صرف وہی کمانڈز انہیں استعمال کرتی ہیں جو ان کا ذکر کرتی ہیں۔ روٹ کے بغیر ونڈوز فائل شیئرنگ پورٹ 445 کے بجائے 4445 استعمال کرتی ہے، اور FUSE پر مبنی ٹولز جیسے `sshfs` دستیاب نہیں ہوتے۔

## 16. مسائل کا حل

- اگر کوئی کمانڈ موجود نہ ہو تب بھی اسے لکھیں؛ نبراس درست پیک تجویز کرے گا۔
- اگر انسٹالیشن رک جائے تو وہی `install` کمانڈ دوبارہ چلائیں؛ ڈاؤن لوڈ وہیں سے جاری رہتا ہے اور اس کی جانچ کی جاتی ہے۔
- `nibras-reload-settings` سیٹنگز فائلوں میں کی گئی تبدیلیاں لاگو کرتی ہے۔
- اگر ایپ اچانک بند ہو جائے تو غلطی کی رپورٹ `crash.txt` میں محفوظ ہو جاتی ہے، اور اگلی بار کھولنے پر ایپ اسے دکھانے اور شیئر کرنے کی پیشکش کرتی ہے۔ GitHub پر مسئلہ رپورٹ کرتے وقت براہ کرم یہ فائل منسلک کریں۔

## 17. اکثر پوچھے جانے والے سوالات

**کیا نبراس ٹرمینل مفت ہے؟** جی ہاں۔ یہ اوپن سورس ہے۔

**کیا اسے روٹ کی ضرورت ہے؟** نہیں۔ سب کچھ روٹ کے بغیر چلتا ہے؛ صرف چند سسٹم سطح کے کام محدود ہیں، جیسا کہ اوپر بتایا گیا ہے۔

**ایپ اتنی چھوٹی کیوں ہے؟** اس میں صرف Alpine Linux اور تراجم شامل ہیں۔ باقی سب کچھ ضرورت پڑنے پر `install` سے ڈاؤن لوڈ ہوتا ہے۔
