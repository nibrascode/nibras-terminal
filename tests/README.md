# Yoxlama

Bu qovluq avtomatik test runner daşımır. Buraxılışdan əvvəl siyahı
`documentation/Nibras_Terminal_Texniki_Komutlar.txt` bölmə 13-dədir.

İndi yoxlana bilən hissə: kataloq JSON-u və SHA-256. Release yükləndikdən sonra:

```
sha256sum -c catalog/SHA256SUMS
```

Böyük arxivlər git-də deyil, `payloads-0.1` release-indədir.
